# 加油站班次交接 · 三账差异归因台

每班按油品录入**油枪泵码增量、罐存变化、收款合计**三账，自动换算体积/金额差异并归因；
来源缺失、跨日回绕超过一次、班次时段重叠时禁止复核；复核后冻结原始三账，更正只能带原因生成新版本。

- 技术栈：Vue 3 + Vite + TypeScript + Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 规则/持久化测试：`npm test`（Node 内置 test runner + tsx）

## 分层结构（归因规则 / 持久化 / 页面分开实现）

```
src/
├── domain/                # 纯领域层，不依赖 Vue、Pinia、localStorage
│   ├── types.ts           # 三账、班次、版本、阈值等模型
│   ├── rules.ts           # 规则引擎：泵码回绕换算、三账差异、复核校验、泵码继承
│   └── seed.ts            # 演示数据（一致 / 差异待归因 / 回绕阻塞 / 时段重叠 / 更正链）
├── persistence/
│   └── store.ts           # localStorage 读写、结构校验与损坏回退
├── stores/
│   └── shifts.ts          # Pinia：编排规则与持久化（录入/复核/更正/删除）
└── components/            # 页面层
    ├── NewShiftForm.vue   # 新增班次（默认接上一班结束时间）
    ├── ShiftChain.vue     # 班次链（按开始时间排序）
    ├── ShiftDetail.vue    # 版本关系、复核冻结、带原因生成新版本
    ├── FuelLedgerCard.vue # 单油品三账录入 + 差异换算 + 归因
    ├── ConflictPanel.vue  # 冲突清单（班次/油品/三账数值/触发规则）
    └── NumInput.vue
```

## 业务规则

1. **泵码继承**：新班次每把枪的起始泵码自动取时间上前一班次最新版本的结束泵码；首班手工录入。
   单枪增量 = 结束 − 起始 + 回绕次数 ×（字轮满度 + 1）。
2. **禁止复核的条件**：
   - 来源缺失：三账任一数值未录全；
   - 跨日回绕超过一次（`wrapCount > 1`）；
   - 班次时段与其他班次重叠；
   - 结束时间不晚于开始时间。
3. **差异归因**：按油品做三组换算比较（阈值：体积 50L、金额 100 元）：
   - 油枪增量 × 罐存发油量（L）；
   - 油枪体积×单价 × 收款合计（元）；
   - 罐存体积×单价 × 收款合计（元）。
   任一差异绝对值超阈值，必须选择「设备计量 / 库存损耗 / 收款差错」并填写依据；
   未超阈值的差异不允许保留归因。
4. **冻结与版本**：复核通过后原始三账冻结不可改；补充更正必须填写原因，
   生成挂在上一版本上的新版本草稿，重新走复核，形成 v1 → v2 版本链。
5. **持久化**：所有数据写入 localStorage（`gas-shift-reconcile-v1`），
   刷新后班次链、差异归因、版本关系保持一致；结构损坏时回退内置演示数据。
